# Employee Management System (MERN Stack)

This project is a full-stack Employee Management System built using the MERN stack (MongoDB, Express, React, and Node.js). It allows users to add, view, update, and delete employee records through 
a responsive and user-friendly interface. The frontend is developed using React, while the backend uses Node.js and Express with MongoDB as the database. The application supports REST APIs for data 
operations and follows a modular project structure with separate frontend and backend folders. To run the project locally, install dependencies using npm install in both frontend and backend folders,
start the backend server, then run the frontend and open the application in the browser at http://localhost:3000.
